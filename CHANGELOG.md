# Changelog

## 0.2.0 — Functional preview source

- Added SAF-backed copy, move, rename, delete, folder creation, ZIP creation and ZIP extraction.
- Added verified file copy, safe move fallback, conflict-safe unique names/skip behavior, and provider-aware errors.
- Added persistent rule management, match preview/manual execution, periodic detection, notification actions, and local operation history with supported undo actions.
- Added persistent favorites, sorting, grid/list mode, settings, and dark/dynamic theme support.
- Added archive extraction limits and refused silent file replacement.
- Updated Android 10 compatibility and privacy documentation.
- Build and API 29 device verification are still outstanding in the authoring environment.
